# Third-party and course materials

## CS 61B BYOW framework

The project includes framework code and materials supplied for UC Berkeley CS 61B, Fall 2024, including tile rendering, utilities, demos, and autograder support. Existing comments are retained. No independent license for these course materials was supplied in the local project. Keep the repository private under the course policy; this document does not grant additional rights.

## Princeton Algorithms library

`lib/algs4.jar` is the unmodified library already present in the local CS 61B dependency collection. It provides `edu.princeton.cs.algs4.StdDraw`. The JAR also contains Java source files and its original `COPYING` entry.

The JAR's existing GPL version 3 license text is additionally preserved verbatim in `third_party/algs4-COPYING.txt`. Library information: [Algorithms, 4th Edition](https://algs4.cs.princeton.edu/code/). The dependency's terms apply to that dependency; no blanket license is asserted for the rest of this course archive.
